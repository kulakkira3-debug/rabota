# Музыкальный стриминг (Music Streaming Database)

Реляционная база данных для музыкального стримингового сервиса, разработанная на **MS SQL Server**. Проект включает полную схему хранения данных о треках, альбомах, артистах, пользователях, плейлистах и истории прослушиваний.

## Описание проекта

Проект представляет собой учебную базу данных, реализующую функционал музыкального стримингового сервиса (аналог Spotify или Яндекс.Музыки). База данных спроектирована с учетом нормализации (1НФ и выше) и включает следующие возможности:

-  Хранение информации об **артистах** и **треках**
-  Управление **альбомами** и их трековыми листами
-  Система **пользователей** с ролями (Пользователь, Артист, Администратор)
- Создание **плейлистов** (публичных и приватных)
-  Фиксация истории **прослушиваний** с указанием устройства

---

## Стек технологий

- **СУБД:** Microsoft SQL Server
- **Инструмент разработки:** SQL Server Management Studio (SSMS)
- **Язык запросов:** T-SQL
- **Дополнительно:** Visual Studio 2022 (для клиентского приложения)
